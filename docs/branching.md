# Ramas y trazabilidad
`main` es estable. Trabajar en `feature/*`, `fix/*` y `refactor/*`. Crear Issues con responsable, prioridad, estimación, estado y criterios de aceptación. Vincular commits y PR con `Refs #ID` o `Closes #ID`. Se requieren al menos seis PR reales, revisados desde la segunda cuenta. No crear evidencias o fechas ficticias.
